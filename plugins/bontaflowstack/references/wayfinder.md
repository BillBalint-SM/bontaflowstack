# Wayfinder evidence contract

Wayfinder answers “where are we, and what is the next useful step?” from the
current project, not from memory alone.

Read the essential context first. Resolve only relevant detail pointers with
`memory history`, `workflow resume` or, when the goal concerns parallel work,
`tasks list` followed by `tasks status` for the matching plan. Check current hashes, branch and recorded evidence before treating prior success as current. A stale
or blocked result cannot make dependent work ready. An unresolved product choice
stays waiting.

Give one next step tied to the active goal and its actual prerequisite. If work
is paused, point to load/resume. If the request is a new task, point to router.
If the goal is complete, report closure. For unfinished work with no useful next
action, state the missing input/capability and the smallest question needed.
Wayfinder does not create workflow or memory records,
start workers or edit project state.
